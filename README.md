# Osteolifting — Landing Page

Landing page for the 7-day free strength-training challenge for women with
osteopenia/osteoporosis (Hebrew, RTL).

## Structure

- `index.html` — the full page (self-contained CSS/JS, Google Fonts: Heebo + Assistant)
- `images/` — real product screenshots used in the phone mockups

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Known placeholders

Search the page for `Placeholder` to find remaining spots that need real
assets before launch: the intro video, Lisa's photo, the WhatsApp number,
two testimonial quotes/photos, and the `og:image` (1200×630).
